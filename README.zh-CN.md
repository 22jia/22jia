## 🧭 我的产品习惯

- **先讲清任务。** 谁在什么情境下，想完成什么，卡在哪里。
- **先走通闭环。** 用可体验的原型验证核心路径，再讨论扩展。
- **让 AI 可检查。** 给出依据、保留未知信息，明确人工接手的位置。
- **让证据匹配结论。** 功能演示、用户验证与业务效果分别记录。

各项目处于不同阶段；具体实现、示例性质和待验证内容，见对应 README。
